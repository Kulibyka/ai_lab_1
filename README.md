# Нейросетевой фреймворк на NumPy

Минималистичный, но мощный фреймворк для глубокого обучения, написанный на Python и NumPy. 
Проект создан для демонстрации понимания внутренних механизмов работы нейронных сетей: от прямого и обратного распространения ошибки до современных методов оптимизации и регуляризации.

## Особенности

*   **Чистое ядро:** Реализация слоев (`Dense`, `ReLU`, `Dropout`) с ручным выводом градиентов.
*   **Продвинутые оптимизаторы:** Поддержка **SGD** и **Adam** (с коррекцией смещения и моментами).
*   **Регуляризация:** Встроенная поддержка **Dropout** и **L2-регуляризации** (Weight Decay) для борьбы с переобучением.
*   **Инженерные абстракции:** Собственные реализации `Dataset` и `DataLoader` для эффективной работы с батчами.
*   **Модульность:** Чистая архитектура, позволяющая легко добавлять новые слои или функции потерь.

## Структура проекта

```text
project/
── core/
│   ├── __init__.py       # Экспорт компонентов ядра
│   ├── data.py           # Dataset и DataLoader
│   ├── layers.py         # Слои сети (Dense, ReLU, Dropout)
│   ├── losses.py         # Функции потерь
│   ├── mnist.py          # Основной скрипт обучения
│   ── optimizers.py     # SGD и Adam
── tests/
    └── experiment_dropout.py  # Эксперименты с регуляризацией
```

## Установка и запуск
```bash
pip install -r requirements.txt
#Запустить обучение на MNIST
python core/mnist.py

#Запустить экспиримент по сравнению регуляризации
python tests/experiment_dropout.py
```
